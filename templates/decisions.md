# Decisions

Short ADR-style log of choices that are expensive to re-litigate. Answers the
question Claude and new contributors keep asking: *why is it like this?*

Without this file, that answer gets re-derived from git archaeology every time —
which is both slow and, on a Pro plan, expensive.

**Format:** newest first.
